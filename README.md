# BindShifter

Аддон для World of Warcraft 3.3.5a (Warmane): профили назначений клавиш и переключение между Bartender4 и стандартными панелями.

## Возможности

- **Профили биндов.** Сохраните текущие клавиши под именем и применяйте их на любом персонаже аккаунта.
  - Снимок полный: кнопки панелей, заклинания, макросы, предметы и кнопки других аддонов.
  - Профиль можно переименовать, дублировать и удалить.
- **Режим панелей.** Профиль помнит, был ли включён Bartender4, и его профиль.
  - Если вы применяете профиль другого режима, аддон после одного подтверждения включает или выключает Bartender4, перезагружает интерфейс и сам применяет бинды.
- **Конвертация Bartender4 ↔ стандартные панели.** Раскладка переносится по ячейкам:
  - бар 1 ↔ главная панель;
  - бары 3–6 ↔ правая, вторая правая, нижняя правая и нижняя левая панели;
  - пет-бар и бар стоек — между собой.

  У баров 2 и 7–10 нет стандартного аналога. Они попадают в отчёт и сохраняются в профиле, поэтому обратная конвертация возвращает всё как было.
- **Безопасность.**
  - Перед применением показывается предпросмотр.
  - Перед каждой операцией создаётся бэкап. Последнюю операцию можно отменить одной кнопкой, а любой из 20 последних бэкапов — восстановить.
  - В бою аддон ничего не меняет: операция выполняется после боя.
- **Ручные правки.** Если вы поменяли клавиши после применения, у профиля появится пометка «изменено».
  - Правки можно сохранить в профиль, посмотреть или откатить.
  - Сам профиль без вашего действия не меняется.
- **Общие бинды.** Выберите группы команд (движение, чат, выбор цели и т. д.), которые общие для всех профилей. Профили их не трогают.
- **Импорт и экспорт** профиля строкой — для переноса между аккаунтами.
- **Набор биндов.** По умолчанию бинды сохраняются для персонажа. Набор аккаунта можно выбрать в настройках.
- **Язык:** русский и английский.

## Установка

1. Скачайте архив репозитория: https://github.com/Munewxar/BindShifter/archive/refs/heads/main.zip

   Или на странице репозитория нажмите **Code → Download ZIP**.
2. Распакуйте архив. Внутри папки `BindShifter-main` есть папка `BindShifter`: скопируйте **именно её** в `World of Warcraft/Interface/AddOns/`.

   В итоге должен получиться путь `Interface/AddOns/BindShifter/BindShifter.toc`. Если путь `Interface/AddOns/BindShifter-main/...`, игра аддон не увидит.
3. Включите аддон на экране выбора персонажа (кнопка «Модификации»).

Bartender4 не обязателен. Без него не работают только функции режима Bartender4.

## Проверка в игре

Аддон пока не проверялся в клиенте. Порядок проверки описан в [docs/ingame-checklist.md](docs/ingame-checklist.md). Если что-то сломалось, включите показ ошибок (`/console scriptErrors 1`) и пришлите текст ошибки.

## Использование

Откройте **Интерфейс → Модификации → BindShifter** или введите `/bsh`.

| Команда | Действие |
|---|---|
| `/bsh` | открыть панель настроек |
| `/bsh list` | список профилей |
| `/bsh save <имя>` | сохранить текущие бинды в профиль |
| `/bsh apply <имя>` | применить профиль (с предпросмотром) |
| `/bsh undo` | отменить последнюю операцию |
| `/bsh help` | список команд |

Типичный сценарий «два режима»:

1. В режиме Bartender4 настройте клавиши и сохраните профиль `BT4`.
2. Нажмите «Конвертировать»: получится профиль `BT4 (Стандартные панели)`. Можно и настроить второй режим вручную, затем сохранить его.
3. Чтобы сменить режим, выберите нужный профиль и нажмите «Применить», затем «Переключить режим и применить».

## Где хранятся данные

Профили лежат в `WTF/Account/<АККАУНТ>/SavedVariables/BindShifter.lua`. Игра записывает этот файл при выходе или `/reload`. Делайте его резервную копию вместе с папкой `WTF`.

## Разработка

```sh
make deps   # Lua 5.1 + busted + luacheck в .lua/ (нужны uv и компилятор C)
make test   # тесты busted
make lint   # luacheck
make dist   # dist/BindShifter-<версия>.zip
```

Ядро (`BindShifter/Core`) — чистый Lua 5.1 без обращений к API игры, покрыто тестами. Слой игры: `Platform/` и `UI/`. Подробности — в `docs/research.md` и `.specify/memory/constitution.md`.
